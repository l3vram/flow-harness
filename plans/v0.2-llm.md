## Files

### `src/types.ts`
- `Tier = "haiku" | "sonnet" | "opus" | (string & {})`
- `MessageRole = "system" | "user" | "assistant"`; `Message { role: MessageRole; content: string }`
- `Usage { inputTokens?: number; outputTokens?: number }`
- `CompletionRequest { messages: Message[]; tier?: Tier; model?: string; maxTokens?: number; temperature?: number }`
- `CompletionResult { text: string; model: string; provider: string; usage: Usage }`
- `ProviderRequest { model: string; messages: Message[]; maxTokens?: number; temperature?: number }` (normalized; model already resolved)
- `LLMProvider { readonly name: string; complete(req: ProviderRequest): Promise<CompletionResult> }`
- `ModelProfile { tier: Tier; provider: string; model: string }`

### `src/providers/fake.ts` — `FakeProvider implements LLMProvider`
Deterministic, offline. Options `{ name?: string; responder?: (req: ProviderRequest) => string }`.
- `name` default `"fake"`.
- Default responder: `"[fake:<model>] <last user message>"`, trimmed (find the last message with
  role `"user"`; empty string if none).
- Usage: `inputTokens` = sum of word counts over all message contents; `outputTokens` = word
  count of the produced text. Word count = trimmed, split on `/\s+/`; empty string → 0.

### `src/providers/openai-compatible.ts` — `OpenAICompatibleProvider implements LLMProvider`
Talks to any OpenAI-compatible `/chat/completions` (OpenAI, OpenRouter, Groq, Together, vLLM,
LM Studio, Ollama `/v1`, …). Export a `FetchLike` type so tests can inject a fake:

```
export type FetchLike = (url: string, init: {
  method: string; headers: Record<string, string>; body: string;
}) => Promise<{ ok: boolean; status: number; text(): Promise<string>; json(): Promise<any> }>;
```

Options `{ baseUrl: string; apiKey?: string; name?: string; fetchImpl?: FetchLike }`.
- `name` default `"openai-compatible"`. Strip trailing slashes from `baseUrl`.
- `fetchImpl` default = global `fetch` (read it as `(globalThis as unknown as { fetch?: FetchLike }).fetch`;
  if neither option nor global is available, throw a clear error).
- `complete`: POST `${baseUrl}/chat/completions`, headers `{ "content-type": "application/json" }`
  plus `authorization: "Bearer " + apiKey` **only if** `apiKey` is set. Body
  `{ model, messages, max_tokens?, temperature? }` — include `max_tokens`/`temperature` only when
  defined. If `!res.ok` throw `` `LLM request failed ${status}: ${await res.text()}` ``. Parse
  `json.choices?.[0]?.message?.content ?? ""`; `model = json.model ?? req.model`; usage from
  `json.usage.prompt_tokens` / `json.usage.completion_tokens`.

### `src/router.ts` — `ModelRouter`
Constructor `(providers: Map<string, LLMProvider>, profiles: ModelProfile[], defaultTier: Tier = "sonnet")`;
throw if `profiles` is empty.
- `resolve(tier): { provider: LLMProvider; model: string }` — profile by `tier`, else by
  `defaultTier`, else first; throw if the profile's provider name isn't in the map.
- `complete(req: CompletionRequest): Promise<CompletionResult>` — `tier = req.tier ?? defaultTier`;
  resolve; `model = req.model ?? resolved.model`; call `provider.complete(...)`.
- getter `tiers: Tier[]`.

### `src/config.ts` — `routerFromEnv(env: NodeJS.ProcessEnv = process.env): ModelRouter`
`TIERS = ["haiku","sonnet","opus"]`. Helper `modelFor(tier, fallback)` =
`env["FLOW_LLM_MODEL_" + tier.toUpperCase()] ?? env.FLOW_LLM_MODEL ?? fallback`.
- `FLOW_LLM_PROVIDER` (default `"fake"`), lowercased.
- `"fake"`: register `FakeProvider`; profiles `tier → { provider:"fake", model: modelFor(t, "fake-"+t) }`.
- `"openai"` | `"openai-compatible"`: require `FLOW_LLM_BASE_URL` (throw if missing); register
  `OpenAICompatibleProvider({ baseUrl, apiKey: env.FLOW_LLM_API_KEY })`; profiles
  `tier → { provider:"openai-compatible", model: modelFor(t, "gpt-4o-mini") }`.
- else throw `unknown FLOW_LLM_PROVIDER '<kind>' (use 'fake' or 'openai')`.

### `src/cli.ts` (bin `flow-llm`; first line `#!/usr/bin/env node`)
`prompt = process.argv.slice(2).join(" ").trim()`; if empty → stderr `usage: flow-llm <prompt>` and
exit 1. `router = routerFromEnv()`. `tier = process.env.FLOW_LLM_TIER ?? "sonnet"`.
`result = await router.complete({ tier, messages: [{ role:"user", content: prompt }] })`.
stdout: `result.text` + newline. stderr: `` `[${result.provider}/${result.model}] in=${result.usage.inputTokens ?? "?"} out=${result.usage.outputTokens ?? "?"}` ``. Catch → stderr stack, exit 1.

### `src/index.ts`
Re-export everything from types, both providers (incl. `FetchLike`), `ModelRouter`, `routerFromEnv`.

## Tests (vitest, in `test/`) — must pass with no network
- `fake.test.ts` — default echo output + deterministic usage; a scripted `responder`.
- `openai-compatible.test.ts` — inject a `fetchImpl` returning a canned OpenAI response; assert
  the URL is `${base}/chat/completions`, the `authorization` header is `Bearer <key>`, the body's
  `max_tokens`, and the parsed `text` / `model` / `usage`; and that a non-ok response throws with
  the status in the message.
- `router.test.ts` — `resolve` maps tier → model; `complete` via a fake returns the expected
  text/model; `routerFromEnv({})` defaults to fake; `routerFromEnv` with
  `FLOW_LLM_PROVIDER=openai, FLOW_LLM_BASE_URL=..., FLOW_LLM_MODEL=...` builds an
  openai-compatible router with the right model.
