**Goal:** the pieces exist but the CEO is blind to them. Wire them in:

## Part 2 — `@flow/orchestrator` uses risk, and the CLI builds the advisor

### `packages/orchestrator/package.json` + `tsconfig.json`
Add dependency `"@flow/review": "*"` and a tsconfig reference `{ "path": "../review" }`.

### `packages/orchestrator/src/types.ts`
Import `RiskAssessment` from `@flow/review`. Add `risk?: RiskAssessment` to `TaskOutcome`.

### `packages/orchestrator/src/orchestrator.ts`
Import `assessRisk` from `@flow/review`. In the dispatch loop, replace the status logic after
`const result = await this.executor.run(...)` with:
```
const ok = result.verify.ok;
const risk = assessRisk({
  filesChanged: result.files,
  verifyFailed: !ok,
  touchesSecurity: result.files.some((f) => /auth|secret|password|token|crypt|exec|spawn/i.test(f)),
});
let status: "green" | "blocked" | "review";
if (!ok) status = "blocked";
else if (risk.level === "high") status = "review"; // passed verify but high risk — a human must look
else status = "green";
const reason = !ok ? "verify failed" : status === "review" ? "high risk — needs human review" : "";
this.runtime.setStatus(taskId, status, reason);
outcomes[taskId] = { status, files: result.files, verify: result.verify, reason: result.reason, risk };
```
(`Status` from `@flow/core` already includes `"review"`. A `review` task is not `green`/`blocked`, so
`waveDone()` stays false and the run pauses for the human — the intended behavior.)

### `packages/orchestrator/src/cli.ts`
Build a CEO advisor from memory + context and pass it in. Add imports
`import { MemoryStore, searchLessons } from "@flow/memory";` and
`import { ContextEngine } from "@flow/context";`. After computing `base` and before constructing the
`Ceo`, build:
```
const lessonStore = new MemoryStore(join(base, "lessons.jsonl"));
const contextEngine = config.contextRoot ? ContextEngine.index(config.contextRoot) : null;
const advisor = (state: State): string => {
  const parts: string[] = [];
  const lessons = searchLessons(lessonStore.all(), state.objective, 3);
  if (lessons.length > 0) parts.push("Past lessons:\n" + lessons.map((l) => "- " + l.content).join("\n"));
  if (contextEngine) {
    const bundle = contextEngine.assemble({ query: state.objective, tokenBudget: 1200 });
    if (bundle.items.length > 0) parts.push("Relevant files:\n" + bundle.items.map((i) => "- " + i.path).join("\n"));
  }
  return parts.join("\n\n");
};
```
(Import `State` from `@flow/core`.) Then construct the CEO with the advisor:
`const ceo = new Ceo(runtime, router, { advisor });` (replacing the current `new Ceo(runtime, router)`).
Everything else in the CLI (lesson recording after the run, etc.) stays.
