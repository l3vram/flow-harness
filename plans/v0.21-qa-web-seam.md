# v0.21 — `@flow/qa` Layer B: the web-QA seam (offline) — self-built

The first half of Layer B: a structured **web** QA model with a browser abstraction and a deterministic
**FakeWebDriver**, so web verification is testable **offline** (no Playwright, no browser binaries) — the
browser analogue of `@flow/llm`'s `FakeProvider`. The real `PlaywrightDriver` + a live-browser smoke is the
next, supervised increment (v0.22) — it can't live in the offline `npm test`. Reuses the `QAReport` contract.

## Contract (new file `packages/qa/src/web-types.ts`)
```ts
export type WebStep =
  | { kind: "goto"; url: string }
  | { kind: "expectText"; text: string }
  | { kind: "expectSelector"; selector: string }
  | { kind: "screenshot"; name?: string };

export interface WebCriterion { id: string; description: string; steps: WebStep[]; severity?: "low"|"medium"|"high"|"critical"; tags?: string[]; }
export interface WebQARequest { target: string; platform: string; criteria: WebCriterion[]; }

/** Abstracts a browser so web QA runs against real Playwright (later) or the offline FakeWebDriver.
 *  QA never imports Playwright directly. */
export interface WebDriver {
  goto(url: string): Promise<void>;
  pageText(): Promise<string>;
  hasSelector(selector: string): Promise<boolean>;
  screenshot(path: string): Promise<void>;
  consoleMessages(): string[];
  networkRequests(): string[];
  close(): Promise<void>;
}
```

## Engine (`packages/qa/src/web-qa.ts`)
`export async function runWebQA(req: WebQARequest, driver: WebDriver, opts?: { evidenceDir?: string }): Promise<QAReport>`
- Default `evidenceDir` to a temp dir (as Layer A). For each criterion, run its steps in order via the driver:
  `goto` → `driver.goto(resolveUrl(target, url))`; `expectText` → fail if `!(await driver.pageText()).includes(text)`;
  `expectSelector` → fail if `!(await driver.hasSelector(sel))`; `screenshot` → `driver.screenshot(<dir>/<name>.png)` + evidence.
- Stop a criterion at its first failing step. Always write `console.txt`/`network.txt` evidence from the driver.
  On failure, capture a `failure.png` and file **one ticket** (severity default "high", symptom = the failed step,
  evidence, tags from the criterion). `complete` = every criterion passed. Same `QAReport` shape as Layer A.
- `driver.close()` in a `finally`.

## Fake driver (`packages/qa/src/fake-web-driver.ts`)
`FakeWebDriver implements WebDriver`, constructed with `{ text?, selectors?, console?, network? }`: `goto` records the
url (`visited: string[]`), `pageText`→text, `hasSelector`→selectors.includes, `screenshot`→writes a placeholder file,
`consoleMessages`/`networkRequests`→configured arrays, `close`→no-op. Deterministic, offline.

## Tests (`test/web-qa.test.ts`, offline, inject `evidenceDir`)
1. pass: a FakeWebDriver with text "Welcome HELLO" + selector "#app"; criterion goto/expectText("HELLO")/expectSelector("#app")/screenshot
   → `complete`, `driver.visited` contains the resolved url, the screenshot + console.txt exist on disk.
2. fail: text "Goodbye"; criterion expectText("HELLO") with severity "critical", tags ["ui"] → `complete:false`, status "fail",
   one ticket (severity "critical", tags ["ui"], symptom contains "expected text not found"), and `failure.png` exists.
