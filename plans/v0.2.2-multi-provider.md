## `src/providers/anthropic.ts` — `AnthropicProvider implements LLMProvider`
Import `FetchLike` from `./openai-compatible.js` and types from `../types.js`.

Options: `{ apiKey?: string; baseUrl?: string; name?: string; maxTokens?: number; fetchImpl?: FetchLike }`.
- `name` default `"anthropic"`. `baseUrl` default `"https://api.anthropic.com/v1"` (strip trailing
  slashes). `maxTokens` default `4096`. `fetchImpl` default = global `fetch` (resolve via
  `(globalThis as unknown as { fetch?: FetchLike }).fetch`; throw a clear error if neither is set).

`complete(req: ProviderRequest): Promise<CompletionResult>`:
- Split messages by role: `system` = the `content` of every message with role `"system"`, joined
  with `"\n\n"`; `convo` = the remaining messages mapped to `{ role: m.role, content: m.content }`
  (only `user`/`assistant` roles reach Anthropic).
- Build body: `{ model: req.model, max_tokens: req.maxTokens ?? this.maxTokens, messages: convo }`,
  plus `system` only when non-empty, plus `temperature` only when `req.temperature !== undefined`.
- Headers: `{ "content-type": "application/json", "anthropic-version": "2023-06-01" }` plus
  `"x-api-key": apiKey` only when `apiKey` is set.
- `POST ${baseUrl}/messages`. If `!res.ok` throw `` `LLM request failed ${res.status}: ${await res.text()}` ``.
- Parse: `text` = the `text` of every response content block with `type === "text"`, concatenated
  (`(json.content ?? []).filter((b) => b?.type === "text").map((b) => b.text).join("")`);
  `model = json.model ?? req.model`; `usage = { inputTokens: json.usage?.input_tokens, outputTokens: json.usage?.output_tokens }`.
- Return `{ text, model, provider: this.name, usage }`.

## `src/config.ts` — per-tier `routerFromEnv`
Rewrite `routerFromEnv(env = process.env)` to build one provider PER TIER (`haiku`, `sonnet`,
`opus`), each configurable, falling back to the global vars. Register providers in the router's map
keyed by the **tier name**, and set each profile's `provider` to that tier name.

For each tier `t` (with `U = t.toUpperCase()`):
- `kind = (env["FLOW_LLM_" + U + "_PROVIDER"] || env.FLOW_LLM_PROVIDER || "fake").toLowerCase()`
- `apiKey = env["FLOW_LLM_" + U + "_API_KEY"] || env.FLOW_LLM_API_KEY || undefined`
- `baseUrl = env["FLOW_LLM_" + U + "_BASE_URL"] || env.FLOW_LLM_BASE_URL || undefined`
- `model  = env["FLOW_LLM_" + U + "_MODEL"] || env["FLOW_LLM_MODEL_" + U] || env.FLOW_LLM_MODEL || defaultModel(kind, t)`
- `provider = makeProvider(kind, { apiKey, baseUrl })`
- `providers.set(t, provider)`, `profiles.push({ tier: t, provider: t, model })`

Helpers (module-private):
- `makeProvider(kind, { apiKey, baseUrl })`:
  - `"fake"` → `new FakeProvider()`
  - `"openai"` | `"openai-compatible"` → require `baseUrl` (throw
    `"FLOW_LLM_BASE_URL is required when the provider is 'openai'"` if missing) →
    `new OpenAICompatibleProvider({ baseUrl, apiKey })`
  - `"anthropic"` → `new AnthropicProvider({ apiKey, baseUrl })` (baseUrl optional)
  - else throw `` `unknown provider '${kind}' (use 'fake', 'openai', or 'anthropic')` ``
- `defaultModel(kind, tier)`:
  - `fake` → `"fake-" + tier`
  - `openai` → `"gpt-4o-mini"`
  - `anthropic` → `{ haiku: "claude-haiku-4-5", sonnet: "claude-sonnet-5", opus: "claude-opus-5" }[tier]`

Return `new ModelRouter(providers, profiles)`. Because providers are keyed by tier, each tier gets
its own instance with its own key/baseUrl. Note: `CompletionResult.provider` still reflects each
provider's own `name` (e.g. `"fake"`, `"anthropic"`), which existing tests rely on.
