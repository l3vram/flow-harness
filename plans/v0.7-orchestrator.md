# Plan v0.7 — `@flow/orchestrator` (CEO → executor autonomous loop)

Self-contained execution plan. Cold context assumed; everything is here.

**Repo:** `/Volumes/ExtSSD/mac-storage/projects/flow-harness` — git, npm workspaces, TS ESM
`NodeNext` (explicit `.js` import specifiers), `strict` + `noUncheckedIndexedAccess`, Node 22.

**Goal:** the integration seam. A conductor that drives a full autonomous run by wiring the
existing pieces: the **CEO** decides the next move, the **executor** implements each ready task
and verifies it, and the **runtime** tracks status and advances waves. No new judgment logic —
this only glues `@flow/ceo`, `@flow/executor`, `@flow/core` (+ optional `@flow/context`).

Create `packages/orchestrator` = `@flow/orchestrator` (`type: module`, bin `flow-run`). Deps:
`@flow/core`, `@flow/ceo`, `@flow/executor`, `@flow/llm`, `@flow/context` (workspace `*`). No
external runtime deps.

## Files

### `src/types.ts`
```
import type { Tier, Status } from "@flow/core"; // Tier is re-exported by core
import type { CeoDecision } from "@flow/ceo";
import type { VerifyResult } from "@flow/executor";

export interface TaskSpec { id: string; role: string; tier: Tier; deps?: string[]; instruction: string; }
export interface OrchestratorOptions { targetDir: string; maxSteps?: number; contextRoot?: string; }
export interface TaskOutcome { status: Status; files: string[]; verify: VerifyResult; reason: string; }
export interface RunReport {
  runId: string;
  objective: string;
  completed: boolean;
  decisions: CeoDecision[];
  outcomes: Record<string, TaskOutcome>;
  tasks: { id: string; status: Status }[];   // final status of every task
}
export interface RunConfig {
  runId: string;
  objective: string;
  targetDir: string;
  verifyCommand?: string[];
  contextRoot?: string;
  maxSteps?: number;
  tasks: TaskSpec[];
}
```
(If importing `Tier` from `@flow/core` is awkward, import it from `@flow/llm` — both export the
same `Tier`. Pick whichever resolves cleanly.)

### `src/orchestrator.ts` — `class Orchestrator`
Constructor `(runtime: Runtime, ceo: Ceo, executor: Executor, specs: Map<string, TaskSpec>, opts: OrchestratorOptions)`.
Keep a private `ContextEngine | null`: if `opts.contextRoot` is set, `ContextEngine.index(opts.contextRoot)`, else null.

`async run(): Promise<RunReport>`:
```
decisions = []; outcomes = {}; maxSteps = opts.maxSteps ?? 20; completed = false
for step in 0..maxSteps-1:
  decision = await ceo.decide(); decisions.push(decision)
  if action == "complete": completed = true; break
  if action == "await_human": break
  if action == "advance":
    if runtime.waveDone(): runtime.advance(); continue
    else: break                      // CEO said advance but the wave isn't done — stop
  // action == "dispatch": run every currently-ready task deterministically
  ready = runtime.ready()
  if ready.length == 0: break        // nothing to do — avoid spinning
  for taskId in ready:
    spec = specs.get(taskId)
    if !spec: runtime.setStatus(taskId, "blocked", "no task spec"); outcomes[taskId] = {status:"blocked",files:[],verify:{ran:false,ok:false,output:""},reason:"no task spec"}; continue
    runtime.setStatus(taskId, "running")
    context = this.contextFor(spec.instruction)          // "" when no contextRoot
    result = await executor.run({ id: taskId, instruction: spec.instruction }, { targetDir: opts.targetDir, context })
    ok = result.verify.ok                                 // verify.ran===false ⇒ ok true (nothing configured)
    runtime.setStatus(taskId, ok ? "green" : "blocked", ok ? "" : "verify failed")
    outcomes[taskId] = { status: ok ? "green" : "blocked", files: result.files, verify: result.verify, reason: result.reason }
state = runtime.state
return { runId: state.run, objective: state.objective, completed, decisions, outcomes,
         tasks: state.plans.map(p => ({ id: p.id, status: p.status })) }
```
`private contextFor(instruction: string): string` — if the engine is null return `""`; else
`engine.assemble({ query: instruction, tokenBudget: 4000 }).items.map(i => "// " + i.path + "\n" + i.snippet).join("\n\n")`.

### `src/cli.ts` (bin `flow-run`; first line `#!/usr/bin/env node`)
- `configPath = process.argv[2]`; if missing → stderr `usage: flow-run <config.json>` and exit 1.
- Read + `JSON.parse` the config as `RunConfig` (on parse error, stderr + exit 1).
- `base = process.env.FLOW_HOME ?? ".flow"`; `dir = join(base, "runs", config.runId)`.
- `runtime = new Runtime(dir)`; if `runtime.started()` → stderr `run '<id>' already exists` + exit 1;
  else `Runtime.init(dir, config.runId, config.objective)`.
- Register tasks and build the specs map: for each `spec` in `config.tasks`,
  `runtime.addTask(spec.id, spec.role, spec.tier, spec.deps ?? [])`; `specs.set(spec.id, spec)`.
- `router = routerFromEnv()`; `ceo = new Ceo(runtime, router)`;
  `executor = new Executor(router, { verifyCommand: config.verifyCommand ?? [] })`.
- `orchestrator = new Orchestrator(runtime, ceo, executor, specs, { targetDir: config.targetDir, maxSteps: config.maxSteps, contextRoot: config.contextRoot })`.
- `report = await orchestrator.run()`; print `JSON.stringify(report, null, 2)`. Catch → stderr, exit 1.

## Tests (`test/orchestrator.test.ts`) — no network, temp dirs
Use two **separate** scripted `FakeProvider`s so the CEO and executor get their own responses:
```
function ceoRouter(actions: string[]): ModelRouter  // FakeProvider scripted to return
   // JSON.stringify({action, taskIds: [], reason: "r", confidence: 0.9}) for each action, in order
function execRouter(files: {path:string;content:string}[]): ModelRouter // FakeProvider always returning
   // JSON.stringify({ files, reason: "done" })
```
(Reuse the `scripted` responder pattern from `packages/ceo/test/ceo.test.ts`.)

- **Happy path, two tasks (b deps a):** seed a Runtime (temp dir) via `Runtime.init` + `addTask`
  for `a` and `b` (b deps `["a"]`). Ceo scripted `["dispatch","advance","dispatch","complete"]`;
  Executor with `execRouter([{path:"out.txt",content:"x"}])` and **no** verifyCommand (so verify
  passes trivially). `targetDir` = a temp dir. Run → `report.completed === true`, both `a` and `b`
  outcomes `green`, and the executor's file exists under `targetDir`.
- **Verify failure blocks a task:** one task `a`; Ceo scripted `["dispatch","await_human"]`;
  Executor with `verifyCommand: ["node","-e","process.exit(1)"]`. Run → `report.completed === false`,
  `outcomes.a.status === "blocked"`, `outcomes.a.verify.ok === false`.
- **No spec is handled safely:** a Runtime task with no matching spec in the map → dispatched step
  marks it `blocked` with reason "no task spec" and the loop does not throw.
