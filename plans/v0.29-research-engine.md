# v0.29 — `@flow/research`: research before implementing (LLM v1) — self-built

Priority-1 research: a capability that, given a question or an area of uncertainty, produces **structured
findings + sources** the CEO/executor can use as context before writing code. v1 synthesizes the model's
knowledge (an LLM step + deterministic parse, offline-testable — same shape as `@flow/planner`/`@flow/verify`);
a real web/GitHub/registry **search provider** (fetch + a search API) plugs in behind the same function later.
Standalone for now; wiring "research-before-implement" into the loop is a follow-up.

## Contract (`packages/research/src/types.ts`)
```ts
export interface ResearchReport {
  query: string;
  summary: string;      // a short synthesis
  findings: string[];   // concrete key points / recommendations
  sources: string[];    // URLs or references the model suggests (to verify later)
}
```

## Files (new package; mirror `@flow/verify`)
1. `packages/research/package.json` — name `@flow/research`, dep `@flow/llm`, no bin.
2. `packages/research/tsconfig.json` — references `../llm`.
3. `packages/research/src/prompt.ts` — `buildResearchMessages(query, context?): Message[]`. System: "Research the
   question for a software engineer about to implement it. Reply with ONLY a JSON object
   `{ summary: string, findings: string[], sources: string[] }` — findings are concrete, actionable points;
   sources are docs/URLs to verify. If unsure, say so in a finding." User: the query + optional context.
4. `packages/research/src/parse.ts` — `parseResearch(query, text): ResearchReport`: slice first `{`..last `}`,
   `JSON.parse`, normalize (summary string; findings/sources = arrays of strings else `[]`); throws
   `"research: no parseable JSON"` when absent.
5. `packages/research/src/research.ts` — `research(router, query, context?, opts?: { tier?: string }): Promise<ResearchReport>`
   — `buildResearchMessages` → `router.complete({ tier: opts?.tier ?? "opus", messages })` → `parseResearch(query, text)`.
   Empty query → an empty report (no LLM call).
6. `packages/research/src/index.ts` — export prompt/parse/research/types.
7. `packages/research/test/research.test.ts` — offline: a scripted router returns `{summary, findings, sources}` →
   `research` returns the parsed report; empty query → empty report without calling the router; `parseResearch`
   handles embedded prose and defaults missing arrays to `[]`.
8. `tsconfig.json` (root) — add `{ "path": "packages/research" }`.
