# v0.30 — `@flow/eval`: an objective evaluation engine (deterministic) — self-built

Priority-1 evaluation: score a run **objectively** from its facts — not an LLM opinion. Deterministic and
dependency-free (the shape of `@flow/review`/`@flow/converge`): given a flat summary of a run's signals, produce a
0–100 score across dimensions, plus a `compare` to diff two runs across versions.

## Contract (`packages/eval/src/types.ts`)
```ts
export interface EvalInput {
  tasksTotal: number; tasksGreen: number; tasksBlocked: number; tasksReview: number;
  criteriaTotal: number; criteriaPassed: number;   // acceptance criteria verified by QA
  criticalTickets: number;                          // high/critical-severity QA tickets
  attempts: number;                                 // total executor attempts across tasks
  tokens?: number;
}
export interface Dimension { name: string; score: number; detail: string; }
export interface EvaluationReport { score: number; dimensions: Dimension[]; summary: string; }
export interface Comparison { scoreDelta: number; byDimension: { name: string; delta: number }[]; verdict: "better" | "worse" | "same"; }
```

## Engine (`packages/eval/src/evaluate.ts`, `compare.ts`)
`evaluate(input): EvaluationReport` — deterministic dimensions (each 0–100), overall = weighted sum:
- **completion** `tasksGreen/tasksTotal` (w .25) · **verification** `criteriaPassed/criteriaTotal` (w .35) ·
  **stability** `(tasksTotal-tasksBlocked)/tasksTotal` (w .15) · **efficiency** `100 - 10·max(0, attempts-tasksTotal)`
  (w .10) · **safety** `100 - 25·criticalTickets` (w .15). A `whole<=0` ratio scores 100 (nothing to fault); all
  clamped to 0–100.
`compare(a, b): Comparison` — score delta, per-dimension delta, and a `better`/`worse`/`same` verdict.

## Tests (`test/eval.test.ts`, offline)
- a perfect run (all green, all criteria passed, no blocked/tickets/extra attempts) scores 100;
- a poor run (blocked tasks, criteria failed, critical tickets, extra attempts) scores low, and `verification`
  reflects the failed criteria;
- `compare(poor, perfect).verdict === "better"` with a positive `scoreDelta`.
